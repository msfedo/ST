# ST
Sample codes for peripherals of ST32 MCU, MPU based  NUCLEO and other DEV Boards.

This Repo contains STM32 MCU & MPU project files created using STM32CubeMX & STM32CubeIDE.

# Purpose of this Repo!!!
This repo is to save others time and so others won't have to face the same issues. Doing so makeing world a better place.
